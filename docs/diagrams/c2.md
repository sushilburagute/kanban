# C2 — Container View

```mermaid
graph TD
    user([Primary User<br/>Product/Project Lead]) -->|taps| nextApp[Next.js 15 App Router<br/>React 19 UI (CSR heavy)]
    nextApp -->|Local persistence| indexedDB[(Browser IndexedDB<br/>Boards + Tasks Stores)]
    nextApp -->|Web Fonts + Tailwind CSS| cdnAssets[(Static Assets)]
    nextApp -->|Client events / web-vitals| ga[Google Analytics (gtag)]
    nextApp -->|OS theme preference| themeAPI[(matchMedia / prefers-color-scheme)]
```

- Runtime is client-heavy; even though Next.js can SSR, kanban flows mount as `"use client"` modules.
- IndexedDB is the sole data store; there is no backend API.
- Google Analytics receives navigation/task events via `gtag` plus future web-vitals beacons (see `docs/RUM-WEB-VITALS.md`).
