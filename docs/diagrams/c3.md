# C3 — Component View

```mermaid
graph LR
    subgraph Layout Shell
        layout[RootLayout.tsx<br/>App Router]
        sidebarProvider[SidebarProvider]
        boardsProvider[BoardsProvider]
        themeProvider[ThemeProvider]
        appSidebar[AppSidebar]
    end

    subgraph Feature Routes
        home[app/page.tsx]
        boardPage[app/boards/[boardId]/page.tsx]
        statsPage[app/stats/page.tsx]
    end

    subgraph Domain Hooks
        useBoards[useBoards / BoardsContext]
        useTasks[usePersistentKanbanTasks]
    end

    subgraph Libs
        storage[lib/task-storage.ts<br/>IndexedDB helpers]
        kanbanUtils[lib/kanban.ts<br/>seed + normalization]
        analytics[lib/analytics.ts<br/>gtag shim]
    end

    layout --> themeProvider --> layout
    layout --> boardsProvider --> sidebarProvider --> appSidebar
    home --> useBoards
    boardPage --> useBoards
    boardPage --> useTasks
    statsPage --> useBoards
    statsPage --> storage
    useBoards --> storage
    useTasks --> storage
    useTasks --> kanbanUtils
    boardPage --> analytics
    appSidebar --> analytics
```

- Every route consumes `useBoards`; `board` route also subscribes to the per-board task hook (which writes back to IndexedDB).
- Analytics is fire-and-forget; if `window.gtag` is absent nothing happens.
